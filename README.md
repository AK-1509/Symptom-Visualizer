# Market Landscape

This repository contains **Market Landscape**, a local-first web app that turns a small set of researched competitors into an editable competitive landscape and a presentation-ready graphic.

The app lives in [`competitive-landscape/`](./competitive-landscape). See its [README](./competitive-landscape/README.md) to install, run, and test it, [MODEL.md](./competitive-landscape/MODEL.md) for the analysis model, and [DECISIONS.md](./competitive-landscape/DECISIONS.md) and [VALIDATION.md](./competitive-landscape/VALIDATION.md) for implementation notes.

```sh
cd competitive-landscape
npm install
npm run dev   # http://127.0.0.1:5173
```
